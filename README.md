# 원복프로 (Wonbok Pro) - 인테리어 원상복구 전문가

원상복구 및 철거 전문 서비스를 제공하는 웹사이트입니다.

## 실행 방법

**필수 사항:** Node.js

1. 의존성 설치:
   ```bash
   npm install
   ```

2. 개발 서버 실행:
   ```bash
   npm run dev
   ```

3. 빌드:
   ```bash
   npm run build
   ```

## 주요 기능

- 원상복구 및 철거 서비스 소개
- 포트폴리오 갤러리
- 고객 후기
- 무료 견적 신청
- AI 컨설턴트 (로컬 응답 시스템)

## 기술 스택

- React 19
- TypeScript
- Vite
- Tailwind CSS
